# AR Viewer — тестовый адрес (next)

https://mookcumka.github.io/ar-viewer/next/ — проверка просмотрщика 0.4.0-rc.1 с форматом GBX2/QRL4 и библиотекой семейств v2 (решение Максима 28.10.2026: тестовый адрес, основной просмотрщик не трогаем).

Копия `ar-poc/` из AR-Project, ветка `claude/gbx1-viewer-next` (PR #86), коммит 41b3ff0. Свой service worker со своей областью `/ar-viewer/next/`, кэш основного просмотрщика не затрагивается. Читает и старые QRL1/QRL2.

QR запуска на PDF Exporto ведёт на основной адрес, поэтому для теста открыть этот адрес вручную, затем считывать QR данных.
