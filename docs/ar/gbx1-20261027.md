## Binary framing

`QRL3[4] | SHA256(gzip)[32] | total:u32LE | index:u16LE | count:u16LE |
chunkLength:u32LE | chunk`. Offsets: 0/4/36/40/42/44/48. No additional flags,
version or compression bytes. Count1..6, zero-based index, chunk1..857,
compressed total1..5142, packet<=905. Existing identity includes version+hash+total+count;
conflicting duplicates and mixing QRL2/QRL3 fail. Reordered packets assemble in index order.
SHA is checked before bounded gzip inflation. QRL3 accepts ONLY raw GBX1; GBX1
under QRL1/QRL2 is rejected instead of guessed from metadata.

Raw: `GBX1[4] | version:u16LE=1 | flags:u16LE=0 | scale:f64LE | records:i32LE`.
All coordinates are finite float64 Revit feet, abs(component)<=1e6, absolute Z-up.
Each record starts `kind:u8 | rgba:u8[4]`:

- 0: vertexCount:i32, indexCount:i32, XYZ triples:f64, indices:i32. Index order
  and coordinates retained; open meshes allowed. Invalid/degenerate faces rejected.
- 1: origin + three full edge vectors (four XYZ triples). Nonzero orthogonal,
  positive determinant. Exact oriented box corners/faces from BakedPrimitive.Expand;
  no category assumptions or axis-aligned bounding box substitution. Mirrored source
  bodies use the writer's canonical positive frame; negative determinant is invalid.
- 2: extrusion vector, contourCount:i32, repeated pointCount:i32 + XYZ points.
  Project using the writer's dominant-axis tie rule and 1e7 feet proof grid with
  .NET round-to-even ties. Contours must be coplanar, simple, non-touching;
  outer positive and hole negative winding. Multiple outer regions and nested islands supported.

Expand in source feet first. Convert each position ONCE as `[x,z,-y]*0.3048*scale`.
Subtract the bottom-center calculated across referenced positions of all records;
return that origin as metadata. Mapping has positive determinant, so winding is retained.
Straight RGBA survives byte-exact; existing shaders and file writers handle sRGB/linear
conversion and alpha. UV/textures/PBR/BIM are absent from this AR profile, as reported explicitly.

## Triangulation and rendering

`gbx-geometry.js` is a pure shared decoder with no camera, renderer, storage, network,
model fixtures or album IDs. It returns the same metre/Y-up mesh contract consumed
by existing `qr-geometry.js` -> `buildMeshes` -> Quick Look/WebXR/3D/USDZ/GLB.

Caps use Three.js r164 Earcut (port of mapbox/earcut2.2.4), pinned upstream commit
`a2e9ee8204b67f9dca79f48cf620a34a05aa8126`, `src/extras/Earcut.js`.
`vendor/gbx-earcut.js` changes only the module export wrapper; no upstream algorithm edits.
Three.js port is MIT; original mapbox/earcut is ISC. Both license texts are included. This local module is also cached/packaged;
there are no CDN imports. It is the same Earcut family used in the existing Three renderer.

Aligned multiple holes expose Earcut's filtering of collinear bridge vertices. Conforming
cap refinement inserts each original boundary vertex on incident cap edges before expansion,
preventing T-junctions against the side walls. Each cap is checked with exact integer area,
inside/outside tests and outward orientation. The expanded primitive must have exactly two
opposite uses of every welded edge and positive volume. A malformed contour never silently
becomes a filled polygon or an approximate box. Triangulation may differ from C# Clipper,
but oriented surface coverage must agree.

Exact-equal RGBA records are batched for rendering without welding, quantization or dropping
triangles. Otherwise thousands of tiny boxes could fit compressed data yet create thousands
of draw calls. `records` metadata retains original order, kind, group, index/vertex ranges and
RGBA for independent tests. Index offsets map each record into the batch; raw fallback order
is unchanged after accounting for this offset. This is approved by the exporter coordinator.

## Limits and atomic failure

32MiB raw, 10000 records, 1000000 expanded vertices, 3000000 indices, existing50000
render-triangle limit. Browser acceptance additionally bounds a single extrusion to256 loops
and4096 total contour points, and a whole scene to256 unique RGBA render groups.
These explicit CPU/draw-call limits were communicated to and accepted by Exporto; they are
not silent simplification and do not change binary field widths. Counts/remaining bytes are
checked before allocations, aggregate expansion before triangle append. Self-intersection
checking/refinement is bounded by contour points; near-inexact 2D orientations use exact integer predicates.

Unsupported kinds/versions/flags, NaN/Infinity, invalid axes, short/nonplanar/crossed contours,
invalid indices, missing bytes, trailing bytes, budget overflow, hash/gzip errors fail before a
scene becomes visible. Existing float32 checks in USDZ/GLB reject collapse/normal inversion
rather than silently losing geometry. No partial model or half-valid AR session is exposed.
