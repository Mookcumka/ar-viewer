# AR Viewer

Общий просмотрщик QR-листов AR Style. Здесь лежит только код просмотрщика, одинаковый для всех листов. Модели здесь нет: она записана в QR на самом листе, после `#` в адресе. Часть после `#` браузер на сервер не отправляет.

Адрес: https://mookcumka.github.io/ar-viewer/

- `index.html` — просмотрщик: камера открыта всё время, QR следующего листа меняет модель на ходу; сглаживание маркера; «Quick Look · 1:1» (USDZ собирается в телефоне, `usdz.js`).
- `scan.html` — переадресация на `index.html` (старые QR и иконка «Домой»).
- `sw.js` — офлайн-кэш. При изменении файлов поднять версию `CACHE`.
- `vendor/` — библиотеки фиксированных версий, без CDN (`vendor-local.ps1`).

Исходник: AR-Project, `ar-poc/` (AR Style 0.65, PR #39). Править там, сюда копировать.

## Проверка «Готово без интернета»

1. С интернетом открыть `scan.html` в Safari, дождаться «Ресурсы сохранены офлайн».
2. Поделиться → На экран «Домой».
3. Открыть установленное приложение, разрешить камеру.
4. Авиарежим, закрыть и открыть приложение, считать QR на бумаге.
