# Диагностический маршрут общего AR Viewer

Этот прежний адрес теперь перенаправляет в основной `index.html?diagnostics=1`. Собственных UI, камеры, renderer, codec или USDZ writer здесь нет. Старый launch.svg сохраняется для уже выданных QR запуска. Worker по прежнему scriptURL только мигрирует старый cache-first scope; новые ресурсы берутся из корня общего приложения.

Источник: AR-Project Draft72, commit `4c482cce6446e9577bb321982532656cd065ed28`. См. [общую архитектуру](../../docs/ar/unified-viewer.md). Публикация этой интеграции требует отдельного решения владельца. Наличие кода не доказывает реальный Revit/iPhone AR.
